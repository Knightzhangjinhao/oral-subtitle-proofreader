# 口播字幕校对 Skill

将中文口播录音或录音转写稿整理成适合剪映、CapCut 等剪辑软件导入的字幕文本。

这个 Skill 用于解决口播内容和原始脚本不完全一致的痛点
在整理字幕时，将以录音或录音转写稿为准；原始脚本只用来校对专有名词和明显识别错误，不会把实际口播强行改回脚本。

## 能做什么

- 修正明显错别字和语音识别错误
- 参考原始脚本校对专有名词
- 删除无意义重复和多余语气词
- 保留真实口语表达
- 按语义自然断句
- 标记无法确认的疑似词
- 支持 `TXT` 和 `SRT` 两种输出格式

## 需要提供什么

最少提供其中一种：

- 录音文件
- 录音转写稿

建议同时提供：

- 原始脚本
- 专有名词表，如人名、品牌名、产品名、课程名、行业术语

## 输出格式

### TXT

默认格式，适合复制到剪映、CapCut 或人工检查。

```text
第一部分：最终字幕稿

这里是一条字幕
这里是另一条字幕
同一句内部可以有逗号，但行尾不机械加标点

第二部分：疑似错误词汇

无

第三部分：修改说明

以录音或录音转写稿为准，参考原始脚本修正了明确识别错误和专有名词，并按语义完整优先调整字幕断句。
```

### SRT

适合导入支持 SRT 的剪辑软件。使用 SRT 需要有时间轴，或提供音频文件生成带时间轴的转写结果。

```text
1
00:00:00,000 --> 00:00:02,000
这里是一条字幕

2
00:00:02,000 --> 00:00:04,000
这里是另一条字幕
```

如果没有时间轴信息，不应凭空生成 SRT 时间码，应改为输出 TXT。

## 推荐使用方式

```text
请用口播字幕校对 Skill 处理下面内容。

【输出格式】
TXT 或 SRT，不填则默认 TXT。

【录音转写稿】
粘贴实际录音转文字内容。也可以直接上传录音文件。

【原始脚本】
粘贴原始脚本，可选。

【专有名词表】
粘贴人名、品牌名、产品名、课程名、行业术语，可选。
```

## 工作原则

- 录音或录音转写稿是事实依据
- 原始脚本只作参考
- 不补充录音里没有说过的内容
- 不把口播改写成书面稿
- 不为了字数强行拆散完整语义
- 行尾一般不加句号或逗号
- 无法确认的词使用 `【疑似：XXX】` 标记

## 使用方式

### 安装为 Skill

下载本仓库后，使用根目录中的 Skill 文件：

```text
SKILL.md
```

如果只想复制单个文件，直接复制 `SKILL.md` 即可。

### 调用方式

在处理字幕时，直接说：

```text
请用口播字幕校对 Skill 处理下面内容。
```

然后按“推荐使用方式”里的模板粘贴录音转写稿、原始脚本和专有名词表即可。
